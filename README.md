# 召唤师图鉴

一个纯前端的《魔灵召唤》图鉴工具。导入 SWEX 或代理导出的账号 JSON 后，可查看图鉴点亮状态，并导出适合分享的 PNG 图片。

## 运行

```bash
npm run dev
```

打开 `http://localhost:4173` 查看图鉴；占领战防守攻略查询位于 `http://localhost:4173/guide.html`，两个功能页面相互独立。账号数据只在浏览器内存中处理，不会上传或写入磁盘。

本地编辑信息由 Node 内置 SQLite 写入 `data/codex.sqlite`，需要 Node.js 22.5 或更高版本。

攻略页支持中文名、多条中文别名、完整拼音、拼音首字母和拼音模糊搜索。搜索结果可拖入指定队伍槽位，已选槽位也可拖动换位；选中队长与两名队员后，会按 SWGT 的觉醒形态 ID 生成防守攻略查询链接。

## 数据

- 现行图鉴元数据和图标来自持续更新的 [SWGT](https://swgt.io/controllers/tools/monsterCatalog?displayAs=GRID) 公开图鉴页，并在同步时生成本地快照。
- SWGT 会隐藏已绝版的联动原版；这些历史条目只使用 SWARFARM 作兼容补充，不用它判断新魔灵。
- 已绝版联动魔灵的历史 ID 会并入对应替代魔灵，同一图鉴项可识别联动原版和替代版。
- 中文名按魔灵 ID 从 SWKit 公开图鉴数据同步。
- 赠送魔灵分组只包含原生五星的联动赠送、融合召唤和远古商店兑换单位，并从五系分组中排除。
- 运行 `npm run sync-data` 可重新同步图鉴与本地图标。
- 中文族名在 `data/zh-cn.js` 中维护；也可以在页面中点击魔灵，补充中文名和别名（保存到浏览器 `localStorage`）。
- 点亮状态优先读取 `unit_collection`，并以 `unit_list` 作为兼容补充。
- SWGT API key 仅用于账号/公会数据上传；本站读取公开图鉴，不需要也不会保存该密钥。

默认导出范围为全部原生五星和光暗原生四星，可在导出弹窗中追加当前筛选结果。
